# Design Patterns

Tracks the design patterns used across the `esg-profile` codebase, why each was chosen, and where it's applied. Update this file whenever a new pattern is introduced or an existing one is reworked — do not let it drift from the code.

No patterns yet — the package is still a scaffold (`esg-profile/src/esg_profile/__init__.py` only has a placeholder `main()`). This file will be filled in as the pipeline (ingestion, extraction, scoring, analysis, dashboard) is implemented.

## Format for each entry

```
## <Pattern name>
- **Where:** <file(s)/module(s)>
- **Why:** <problem it solves in this codebase>
```
